# Design CSS para um site do jogo

Antes de alterar o site, inspecione sua estrutura, tecnologia e referência visual. Se ainda não houver site, defina a página e o público a partir do pedido do usuário. Mantenha a identidade da Ilha da Aurora quando o site estiver ligado ao jogo.

Estabeleça uma direção visual concreta: tipografia, paleta, espaçamento, composição e tratamento de imagens. Implemente tokens CSS para os valores repetidos e use HTML semântico. Faça a composição responder a telas grandes e pequenas, com navegação, leitura e controles de toque claros.

Use imagens e ícones de boa qualidade quando agregarem à página. Preserve contraste e estados de foco visíveis. Verifique a página no navegador em largura de computador e celular e corrija cortes, desalinhamentos e interações antes de entregar.

Quando o site for criado ou gerenciado pelo plugin Sites, siga também o fluxo da skill Sites disponível na sessão e adapte este guia à estrutura produzida pelo plugin.
